# Home 欢迎启动页

欢迎页是 `index.html` 外层临时覆盖层，不新增路由，也不改变原首页正文、专题、设备入口或业务逻辑。

## 文字与动画

- 背景按最新色板采用午夜蓝渐变：`#02060E` → `#0356C5`，浅色和深色系统保持一致；不展示钢卷或焊机照片。
- 管理组文字与“欢迎您”均采用样品的系统无衬线粗体，不使用书法体或下载字体。
- 动画参考用户提供的 `welcome.html`：焊缝自左向右扫描，管理组7个字和欢迎3个字依次冰白点亮，转亮蓝、蓝紫，再定型为冰白。文字 `#EDF5FF`，辅助文字 `#B6CDE9`，光束 `#55C9FF`，冷却色 `#8CAEFF`；时序及特效不变。
- 光束从0秒匀速移动，3秒到达终点并开始退场；每个字受热/冷却0.82秒，全部字形1.96秒前完成。“精密焊接”于1.45～2秒淡入；删除“连续轧制”。
- 火花单独参考用户附件“冷轧焊接管理组欢迎您.html”：Canvas随机发射、随机速度及寿命、重力下落、蓝白粒子渐隐；扫过的轨迹随机生成较弱余火。光束仍为原淡亮蓝。粒子上限220，DPR上限2，3秒停止并清空；离开、隐藏或覆盖层移除时清理。没有永久余烬、点击重播或全局pointerdown，不改变文字、背景或行程。
- 旧背景和字体文件保留，但启动页不再引用或预缓存它们。
- 数字3→2→1，3秒后开始整体淡出，约3.5秒移除覆盖层。4.5秒JavaScript与4.8秒CSS保护避免用户被锁住。
- 页面转入后台或离开时清理；浏览器从专题返回时不重播。刷新和重新打开正常播放。
- 减少动态效果模式只保留简单淡入/淡出；没有额外动画依赖。

## PWA

Home候选缓存升级为 `welding-guide-home-v35`，欢迎CSS使用v10查询参数，以替换已发布v34的旧动画。新增独立火花脚本 `js/splash-sparks.js?v=1` 并加入本项目离线清单；缓存清理逻辑未变，只匹配 `welding-guide-home-`，不控制或清理设备PWA资源。

manifest、start_url、scope及现有更新机制保持不变。旧窗口仍在使用旧Service Worker时，应关闭本项目全部窗口后重新打开，使新版本接管。
