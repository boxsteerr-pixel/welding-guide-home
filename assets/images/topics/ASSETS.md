# 专题入口3D插画

使用内置imagegen生成；参考用户提供的三张科技风卡片，透明背景。所有输出已复制到Home仓库。

- principle-3d.png：蓝色金属激光焊接喷头、青蓝光束、金属板与橙白焊接火花。
- history-3d.png：蓝色玻璃档案夹、青色历史箭头与时钟。
- safety-3d.png：蓝色金属盾牌、浅青色勾、全息圆形底座。

最终提示词方向：参考图仅作风格参考；单个主体完整居中、等距三分之四视角、钴蓝金属与半透明玻璃、青色边缘光、透明alpha背景；不含文字、数字、卡片框、背景场景或水印。

UI标题、编号及箭头独立于插画，始终是网页元素。箭头使用Bootstrap Icons的chevron-right，许可证见assets/icons/bootstrap-LICENSE.txt。
